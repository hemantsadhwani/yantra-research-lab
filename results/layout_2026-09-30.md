# Layout router eval, 2026-09-30

**fake providers: proves the harness; the rules backend numbers are real**

The `slm` and `frontier` rows below come from scripted `FakeProvider`s, not from models. No
Ollama server and no Anthropic or Bedrock call was used. Only the `rules` row measures
something real: the threshold classifier in `ingestion/layout_router.py`.

## What was run

- Code: `ingestion/layout_labels.py` (page features, teacher rule), `ingestion/layout_router.py`
  (three backends behind `LayoutClassifier`), `eval/layout_eval.py` (this table).
- Labels: the teacher rule `derive_label` over the parser's own output (tables found by
  PyMuPDF, embedded images, "Figure N" caption lines). Free labels, not human annotation.
- Fake SLM: returns the **rules** label, flipped to a wrong label 8% of the time (seed 7).
- Fake frontier: returns the **teacher** label, flipped 3% of the time (seed 11).
- Frontier cost: Haiku 4.5 list price (`llm_gateway/pricing.py`) over the real prompt's token
  estimate (characters / 4). Schema tokens are not counted, so it is a floor.
- Latency: wall time around each `classify` call on the dev Mac (Intel, 4 cores). For the fake
  rows it is harness overhead, not model latency.

## How to read it

- **The real set is 83% `text`.** Always answering `text` scores 0.83 on it, so the rules
  row's 0.99 is worth 0.16 over that baseline, not 0.99. The two misses are `figure-heavy`
  pages the rules call `mixed` (their cut-off is 1,500 characters; the teacher's is 1,800).
- **No `table-heavy` page exists in the real set.** PyMuPDF found table blocks on only 7
  pages, and each of those also has a figure signal or a table share under 30%, so the teacher
  calls them `mixed` (`parse.py` only scans the first 10 pages for tables). The
  synthetic set is there to exercise that class; the rules get 13 of its `mixed` pages wrong
  as `table-heavy`, because they read line length, not the table's share of the text.
- **Rules vs teacher is not independent.** Both read parser output. The rules use coarse
  counts (table blocks, line length, figure anchors); the teacher uses content shares. So the
  rules score is agreement with a stricter rule over the same signals, not ground truth.
- **The fake rows prove wiring, not models.** The strict schema, the gateway call, the cost
  and latency columns and the agreement column all run end to end. The fake SLM's accuracy is
  just "rules minus 8%", by construction.
- **Cost is real arithmetic.** At Haiku 4.5 list price the frontier tier costs about
  $0.21 to $0.28 per 1,000 pages for this prompt (a floor). Rules and a local SLM cost $0.
