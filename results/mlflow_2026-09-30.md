## Notes

- MLflow 3.x puts the file store in maintenance mode and raises unless
  `MLFLOW_ALLOW_FILE_STORE=true`. `track_run` sets that default for a `file:` URI;
  `make mlflow-ui` sets it for the UI. A `sqlite:///mlflow.db` URI avoids the opt-in.
- Installing `mlflow` 3.16.1 pulls `databricks-sdk`, which wants `protobuf<7`, while
  `grpcio-tools` (via qdrant-client) wants `protobuf>=7.35.1`. `pip check` reports the
  databricks-sdk conflict; local file-store tracking does not use databricks-sdk and works.
- The model registry is not used. Only eval runs (params, metrics, tags) are tracked.
